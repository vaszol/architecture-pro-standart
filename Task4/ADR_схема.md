### предоставить системе кол-центра доступ к ставкам по депозитам

### **Функциональные требования**

| **№** | **Действующие лица или системы**        | **Use Case**                      | **Описание**                                                                                                                                                                                                                                                 |
|-------|-----------------------------------------|-----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1     | Сотрудник кол-центра                    | Консультация по актуальным ставкам | 1. Клиент звонит в кол-центр с вопросом о ставках<br>2. Сотрудник открывает систему кол-центра<br>3. Система отображает актуальные ставки<br>4. Сотрудник консультирует клиента по условиям                                                                  |
| 2     | Сотрудник партнёрского кол-центра       | Консультация по актуальным ставкам | 1. Клиент звонит в партнёрский кол-центр<br>2. Сотрудник открывает систему кол-центра партнёра<br>3. Система отображает актуальные ставки<br>4. Сотрудник консультирует клиента по условиям                                                                  |
| 3     | Система кредитного скоринга             | Обновление ставок в кол-центрах   | 1. Сотрудник отдела кредитования обновляет ставки<br>2. Система автоматически передаёт обновления в систему кол-центра банка через API<br>3. Система формирует файл со ставками для партнёрского кол-центра<br>4. Файл передаётся по SFTP в систему партнёра |
| 4     | Менеджер бэк-офиса депозитных продуктов | Управление ставками депозитов     | 1. Менеджер работает запрашивает ставки из системы кредитного скоринга<br>2. Обновляет ставки в АБС<br>3. Система формирует файл со ставками для партнёрского кол-центра<br>4. Файл передаётся по SFTP в систему партнёра                                    |

### **Нефункциональные требования**

| **№** | **Требование**                                                                                                                       |
|-------|--------------------------------------------------------------------------------------------------------------------------------------|
| 1     | Нужно, чтобы сотрудники кол-центра могли проконсультировать клиентов хотя бы по текущим ставкам банка                                |
| 2     | необходимо подключить к работе партнёрский кол-центр, чтобы также могли проконсультировать клиентов по актуальным депозитным ставкам |
| 3     | нужно наладить процесс передачи информации об актуальных ставках между банком и кол-центром                                          |
| 4     | Кол-центр партнёра готовы получать актуальные ставки в виде файлов, через SFTP-протокол                                              |
| 5     | частота обновления ставок на текущем уровне 1 раз в день                                                                             |
| 6     | частота обновления ставок на финальном уровне от 1 минуты до конца дня если данных для решения достаточно.                           |
| 7     | допустимая задержка доставки файлов текущем уровне 1 раз в день                                                                      |
| 8     | допустимая задержка доставки файлов на финальном уровне от 1 минуты до конца дня если данных для решения достаточно.                 |
| 9     | доступ к API для кол-центра в рабочее время по ключу сотрудника для авторизации и логирования запросов                               |
| 10    | доступ по SFTP для партнерского кол-центра утверждается совместно с принятыми мерами безопасности партнерской стороны                |

### **Решение**
- ставки обновляются раз в день - значит действительны в течении дня
- добавить отправку раз в сутки текущих общих ставок партнерскому call-центру по SFTP
- добавить API в АБС для запросов call-центра банка по общим и персональным ставкам

### **Альтернативы**

1. интеграция call-центров с БД АБС:
2. вынос отдельного модуля для информирования call-центров по ставкам
3. рассылка ставок по email

**Недостатки**
- дополнительная нагрузка на систему АБС
- безопасность персональных данных
- дублирование логики
- зависимость от центральной системы

**ограничения**
- ограничения производительности по количеству запросов
- ограничения по безопасности данных

**риски**
- недоступность системы АБС
- задержки в обновлении рассылки ставок
- превышение времени разработки
