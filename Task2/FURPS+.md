| Код | Требования                                                                                                         | Комментарий                                                                                                                          |
|-----|--------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| F   | Функциональные (Functionality)                                                                                     |                                                                                                                                      |
| F1  | Клиент может подать заявку на депозит, оставив свой номер телефона и Ф. И. О.                                      |                                                                                                                                      |
| F2  | Клиент может подать заявку на депозит, указав счёт и сумму депозита.                                               | Операцию необходимо будет подтвердить с помощью СМС-кода.                                                                            |
| F3  | На этапе MVP предполагается, что заявку на открытие депозита обработает менеджер в бэк-офисе                       | Он подтвердит условия депозита в АБС банка                                                                                           |
| F4  | клиент должен получить СМС-уведомления после подтверждения размера ставки и открытия депозита.                     |                                                                                                                                      |
| F5  | клиенты смогут подавать заявки на кредит в интернет-банке и на сайте                                               |                                                                                                                                      |
| F6  | новый клиент видит предложение открыть кредит по некоторой ставке                                                  | полная информация об возможных условиях кредита хранится в Кредитном конвейере                                                       |
| F7  | После подачи заявки клиенту приходит СМС о том, что нужно прийти в отделение для получения кредита и идентификации | так как клиент новый, можно использовать только общие данные бюро кредитных историй                                                  |
| F8  | менеджер может подать заявку на кредит через АБС                                                                   | нужно учесть, что клиент мог уже получить предварительное одобрение по кредиту на сайте                                              |
| F9  | В интернет-банке клиент видит список доступных кредитов с актуальными условиями так же, как и на сайте             | ещё ему может выводиться предодобренное предложение по кредит, если уже произошел скоринг и была рассчитана приемлемая сумма кредита |
| F10 | добавить информирование клиента по СМС об изменении статуса заявки на кредит                                       |                                                                                                                                      |
|     |                                                                                                                    |                                                                                                                                      |
| U   | Удобство использования (Usability)                                                                                 |                                                                                                                                      |
| U1  | клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него         |                                                                                                                                      |
| U2  | ставки по депозитам сейчас не ведутся нигде, кроме XLS-файлов.                                                     | С ними должны иметь возможность работать сотрудники как бэк-офиса депозитов, так и бэк-офиса кредитов.                               |
| U3  | интерфейс работы будет максимально удобным для клиента                                                             |                                                                                                                                      |
| U4  | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                                   |                                                                                                                                      |
| U5  | нужно придерживаться системы дизайна для приложений, которая принята в компании                                    | привычные цвета и брендированные элементы                                                                                            |
| U6  | Операция на подачу заявки на кредит подтверждается СМС-кодом                                                       |                                                                                                                                      |
|     |                                                                                                                    |                                                                                                                                      |
| R   | Надёжность (Reliability)                                                                                           |                                                                                                                                      |
| R1  | сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                       | лучше избежать прямой работы интернет-банка с API АБС в новом процессе                                                               |
| R2  | необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку                            |                                                                                                                                      |
| R3  | всё работает в одном ЦОД на одной группе серверов                                                                  | У банка есть резервный ЦОД, в случае сбоя можно переключиться на него                                                                |
|     |                                                                                                                    |                                                                                                                                      |
| P   | Производительность (Performance)                                                                                   |                                                                                                                                      |
| P1  | при проведении платежей - быстрая загрузка справочных данных, менее секунды                                        |                                                                                                                                      |
| P2  | заявки на кредит по предодобренным предложениям будут обрабатываться сотрудниками в течение того же рабочего дня   | хотя сейчас заявки попадают в Кредитный конвейер раз в сутки из АБС                                                                  |
| P3  | Кредитный конвейер и система кредитного скоринга учитывают роста нагрузки и горизонтальное масштабирование         |                                                                                                                                      |
|     |                                                                                                                    |                                                                                                                                      |
| S   | Поддерживаемость (Supportability)                                                                                  |                                                                                                                                      |
| S1  | нужно как можно больше использовать технологии, которые уже есть в банке (MS SQL, Oracle)                          | желательно, чтобы внутри банка уже была экспертиза — сотрудники понимали новые технологии                                            |
| S2  | Если нужны очереди сообщений, то лучше использовать Kafka на перспективу.                                          |                                                                                                                                      |
| S3  | стоит подумать о переводе интернет-банка на микросервисную архитектуру                                             | пока только в рамках задачи открытия депозитов                                                                                       |
| S4  | нужно предусмотреть разработку документации для дальнейшего расширения системы.                                    |                                                                                                                                      |
|     |                                                                                                                    |                                                                                                                                      |
| +R  | + Ограничения (Restrictions)                                                                                       |                                                                                                                                      |
| +R1 | с сайта передаётся чувствительная информация                                                                       | Данные необходимо защищать с помощью механизма шифрования трафика.                                                                   |
| +R2 | новому клиенту надо прийти в отделение для идентификации                                                           | банки не могут принимать новых клиентов без личной проверки документов                                                               |
| +R3 | Функционал работы с СМС реализован в ядре системы, требует доработки.                                              | Реализовать такой бизнес-функционал можно силами команды разработки банка.                                                           |
| +R4 | Команда АБС утверждает, что база данных системы уже перегружена.                                                   |                                                                                                                                      |
| +R5 | Онлайн-подача заявок на большое количество продуктов может поставить под угрозу работоспособность банка.           |                                                                                                                                      |
| +R6 | АБС может масштабироваться только вертикально из-за своей базы данных                                              | предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД                |
| +R7 | Система кредитного скоринга испытывает повышенную нагрузку в рабочие часы                                          | её не нужно нагружать дополнительными процессами по предрасчетам скорингов                                                           |
|     |                                                                                                                    |                                                                                                                                      |
